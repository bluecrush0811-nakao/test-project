# 目標とKPI

## 最終目標
**アフィリエイト収益(承認ベース) 月30万円**

## 収益の分解(初期仮説)
以下は一般的な水準をもとにした **仮の数値** です。実績データが2〜4週間分たまったら、分析担当が実数で置き換えてください。

| 区分 | 例 | 平均報酬単価 | 想定CVR | 承認率 | 必要成約数/月 | 必要クリック数/月 | 収益 |
|---|---|---:|---:|---:|---:|---:|---:|
| 高単価 | サービス申込・無料登録など | 5,000円 | 1.0% | 80% | 50件(承認40件) | 5,000 | 200,000円 |
| 中単価 | サブスク・アプリ・講座など | 1,500円 | 2.0% | 85% | 59件(承認50件) | 2,950 | 75,000円 |
| 物販 | Amazon・楽天など | 250円 | 4.0% | 95% | 105件(承認100件) | 2,630 | 25,000円 |
| **合計** | | | | | | **約10,600** | **300,000円** |

- 必要クリック数 ≒ **1日あたり約350クリック**
- アフィリエイト投稿のリンククリック率を1%と仮定すると、アフィリエイト投稿だけで **月約100万インプレッション** が必要
- 収益の柱は高単価案件。物販は信頼づくりと補助的な収益と位置づける

## 月次KPI(担当別)

| 担当 | KPI | 目標値(月) |
|---|---|---|
| 分析 (sns-analyst) | 週次レポート提出 / 打ち手の実行率 | 4回 / 80%以上 |
| 下書き (sns-writer) | 投稿数(価値提供7:アフィリエイト3) | 90投稿(1日3投稿) |
| アフィリエイト (affiliate-manager) | リンククリック数 / 承認報酬額 | 10,600 / 300,000円 |
| チェック (post-checker) | 公開前チェック率 / 規約・法令違反件数 | 100% / 0件 |

## ロードマップ(目安)
最初から月30万円は難しいため、段階的に積み上げます。

| 期間 | フェーズ | 収益目標 | 重点 |
|---|---|---:|---|
| 1〜2か月目 | 土台づくり | 〜1万円 | テーマ確定、価値提供投稿でフォロワー・インプレッションを伸ばす |
| 3〜4か月目 | 収益化テスト | 3〜10万円 | 案件を3〜5個に絞ってテスト、勝ちパターンを見つける |
| 5〜6か月目 | 拡大 | 15〜30万円 | 勝ちパターンの量産、高単価案件の比率を上げる |
