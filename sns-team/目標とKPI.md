# 目標とKPI

## 最終目標
**アフィリエイト収益(承認ベース) 月30万円**

## アカウントのテーマ
| 媒体 | テーマ | 想定読者 |
|---|---|---|
| X | 投資・副業に**リアルに挑戦していく過程**の発信(実際の金額・成功も失敗も公開) | これから投資・副業を始めたい20〜40代の会社員 |
| Threads | **地元・沖縄のレアなお店、自動販売機、伝統芸能**の発信 | 沖縄好き・沖縄旅行を計画している人、県民 |

2つの媒体はテーマも読者も別。投稿の使い回しはせず、それぞれ独立したアカウントとして育てる。

## 収益の分解(初期仮説)
以下は一般的な水準をもとにした **仮の数値** です。実績データが2〜4週間分たまったら、分析担当が実数で置き換えてください。

| 媒体 | 区分 | 案件の例 | 平均報酬単価 | 想定CVR | 承認率 | 必要成約数/月 | 必要クリック数/月 | 収益 |
|---|---|---|---:|---:|---:|---:|---:|---:|
| X | 高単価 | 証券口座開設、クレジットカード、ポイントサイト登録 | 5,000円 | 1.0% | 80% | 50件(承認40件) | 5,000 | 200,000円 |
| X | 中単価 | 副業向けサービス・ツール(クラウドソーシング、家計簿アプリ、書籍など) | 1,500円 | 2.0% | 85% | 36件(承認30件) | 1,800 | 45,000円 |
| Threads | 旅行・体験 | 宿泊予約、アクティビティ・伝統芸能の体験予約 | 500円 | 2.0% | 80% | 100件(承認80件) | 5,000 | 40,000円 |
| Threads | 物販 | 沖縄の特産品・お土産(楽天・Amazon) | 250円 | 4.0% | 95% | 64件(承認60件) | 1,600 | 15,000円 |
| **合計** | | | | | | | **約13,400** | **300,000円** |

- 必要クリック数 ≒ **1日あたり約450クリック**
- 収益の約8割は X(投資・副業)の高単価案件が担う。Threads は単価が低めなので、収益よりも **ファンづくりと将来の地元店とのタイアップ案件(直接契約)** の土台と位置づける
- 金融系の案件はASPの審査や表現ルールが厳しい。「実際に口座を開いて使っている」実績投稿を積み上げてから紹介する

## 月次KPI(担当別)

| 担当 | KPI | 目標値(月) |
|---|---|---|
| 分析 (sns-analyst) | 週次レポート提出 / 打ち手の実行率 | 4回 / 80%以上 |
| 下書き (sns-writer) | 投稿数(価値提供7:アフィリエイト3) | X 90投稿(1日3投稿)/ Threads 60投稿(1日2投稿) |
| アフィリエイト (affiliate-manager) | リンククリック数 / 承認報酬額 | 13,400 / 300,000円 |
| チェック (post-checker) | 公開前チェック率 / 規約・法令違反件数 | 100% / 0件 |

## 媒体ごとの役割
| 媒体 | 役割 | 運用のポイント |
|---|---|---|
| X | 収益の柱(投資・副業) | 拡散(リポスト)で新規読者に届く。毎月の損益・副業収入を数字で公開する「挑戦記録」で継続フォローを生む。外部リンク付きの投稿は表示が伸びにくい傾向があるため、本文で価値を出し、リンクはリプライ(自分の返信)やプロフィールに置く形もテストする |
| Threads | 沖縄ファンづくり・旅行需要の取り込み | 会話・共感型の投稿が伸びやすい傾向。写真付きの現地レポートで「行ってみたい」を作り、旅行・体験予約につなげる |

- 媒体ごとにどれだけ稼げているか分かるよう、**X用とThreads用でアフィリエイトリンク(トラッキングID)を分ける**
- Threads の公式インサイトはリンククリックが取りにくいため、クリック・成約はASP側の数値で計測する

## ロードマップ(目安)
最初から月30万円は難しいため、段階的に積み上げます。

| 期間 | フェーズ | 収益目標 | 重点 |
|---|---|---:|---|
| 1〜2か月目 | 土台づくり | 〜1万円 | X: 挑戦開始宣言と毎週の進捗公開 / Threads: 沖縄ネタのストック作り。価値提供投稿でフォロワーを伸ばす |
| 3〜4か月目 | 収益化テスト | 3〜10万円 | 案件を3〜5個に絞ってテスト、勝ちパターンを見つける |
| 5〜6か月目 | 拡大 | 15〜30万円 | 勝ちパターンの量産、高単価案件の比率を上げる |
