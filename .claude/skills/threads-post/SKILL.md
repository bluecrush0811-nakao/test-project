# Threads 投稿文作成スキル

Threads(スレッズ)で伸びる投稿文を、タップ数を最大化する型に沿って作成する。
参考: YouTube動画「【月50万達成】結局Threads×Claudeが一番熱い【AI副業】」で紹介されている
投稿文の条件をまとめたもの(動画内スクリーンショットからの書き起こし。画面外で読み取れなかった
部分は含まれていない可能性がある)。

## 大前提

- Threadsで伸びるかどうかは「タップ数」で決まる。いいね・拡散・フォロワー数より、
  投稿をタップして中まで見てもらえるかが重要。
- だから投稿の続き(答え・詳細)は**コメント欄**に置き、本文は「タップしたくなる状態」で
  終わらせる。
- 読むか読まないかは一行目の0.2秒で決まる。
  **一行目で止める → 本文を読ませる → コメント欄をタップさせる** の3段で設計する。

## 1. 一行目の条件

- 0.2秒で意味が分かる文にする。「何の話?」と一瞬でも考えさせたら、指は次の投稿へ行く。
- 誰が見ても有益そうに見える内容にする。
- **強い言葉**を入れる。ドキッとする言葉に目は勝手に向く。
  - 例:「個人情報が全部漏れてます」
  - ※「炎上覚悟で言います」は使われすぎているので、そのまま使わない。自分が「強い」と
    感じてメモしたワードを使う。
- 強い言葉が思いつかないときは「会話(セリフ)」にする。セリフをそのまま置くと状況が
  一瞬でイメージできる。
  - 例:「面接10秒で『あ、君採用ね』って言われた」
  - 例:「会社の同僚に『若返った?』って言われたファンデがあって」
- 常識を一瞬でひっくり返す**意外性**を入れる。
  - 例:「アマニ油はマジでヤバい食べ物です」(体にいいはずの油を「ヤバい」と言うから、
    どっちの意味か気になる)
- **具体的な名詞と数字**を、どれか1つは必ず入れる(商品名・金額・年数など)。
  - OK: 「アマニ油」「シミ対策18年」 / NG: 「話題の油」(何の油か考えさせた時点で負け)
  - 数字はなるべく具体的に。「高額なスキンケア」ではなく「2万以上のスキンケア」と書く。
  - 自分の経歴・実績も数字つきで名乗ると信用になる。
    例:「薬剤師12年の僕が断言するけど」「シミ対策18年やってきて」
- 「これ私のことだ」と読者が一瞬で分かるようにする。
  - 例:「妊娠したら」「月収20万の会社員に言いたい」
  - ※「全員やった方がいい」のように対象を広げすぎると、逆に誰も自分のことだと
    思わなくなる。
  - ターゲットは実際に人数が多い層を選ぶ。「NISAをやめようか迷ってる人へ」
    「LDLが高くて卵や肉を控えている人」は狭すぎて伸びない。
    「健康診断でLDL高いって言われた人」まで広げる。
  - 本人が普段から意識している悩みで名指しする。「本を読んだ後にすぐ内容を忘れて
    しまう人へ」は、実際そうであっても普段意識していないことが多く、自分のことだと
    気づいてもらえない。

### 一行目でやってはいけないこと

- 当たり前のことを書かない。「投資は大事です」「伸ばしたいなら毎日投稿してください」は
  「そらそうだろ」で終わる。
- 指示語(それ・これ・あれ・そこ)を使わない。「肌荒れ治らん人、原因はそこ」は
  「そこってどこ?」と考えさせるだけで離脱される。

## 2. 本文の書き方

- スマホで見て**3〜8行**に収める。
  - 長すぎる = 全部読んだ上でコメント欄までタップするのが億劫になる
  - 1〜2行 = 何も渡せずフォローに繋がらない
- 本文の書き出しにもインパクトのあるワードを入れる(一行目と同じ考え方)。
  例:「ガチ炎上覚悟で言うけど」から書き出す。
- 一文をとにかく短くする。「そもそも」「やっぱり」「〜くらい」など、無くても意味が
  通る言葉は削る。
- 目立たせたい単語は「」(カギカッコ)で囲む。
- 漢字にできる言葉をひらがなのままにしない。誤読を招くことがある。
  例:「置いてある」をひらがなで「おいてある」と書くと「おいおい」と読めてしまう。

## 3. アフィリエイトを組み込む場合

商品・サービス紹介やアフィリエイトリンクを絡めた投稿を依頼された場合は、通常の型に加えて
以下も守る。

- **比率を意識する**。宣伝色のある投稿ばかりにしない。価値提供のみの投稿:アフィリエイト
  絡みの投稿 = 目安9:1程度。依頼が複数本セットの場合、この比率で構成を提案する。
- **リンクは本文に貼らずコメント欄(セルフリプライ)に置く**。本文にリンクを含めると
  リーチが落ちやすいと言われているため、通常の「答えはコメント欄」の型がそのまま使える。
- **一人称の体験ベースで書く**。「これを紹介します」ではなく「これ使ってます」
  「実際に失敗して学んだこと」のような、自分の体験として書くと不自然な宣伝感が出にくい。
- **「【PR】」等を本文の目立つ位置(冒頭付近)に明記する**。日本では景品表示法の
  ステルスマーケティング規制により、対価を得て行う紹介は広告であることを明示する
  義務がある。「#PR」「#広告」をハッシュタグとして入れる、または本文冒頭に
  「【PR】」と書くなど、投稿を見ただけで広告だと分かる書き方にする。
  これは省略してはいけない。
- アフィリエイトリンク自体(実際のURL)はユーザー自身のものに差し替えてもらう前提とし、
  プレースホルダーであることが分かる形で案内する。

## 4. 伸びやすくする追加テクニック

基本の型(一行目→本文→コメント欄)に加えて使える補助テクニック。

- **一行目のあとに空白行(改行)を入れる**。一行目だけを画面に見せ、本文を少し下にずらす
  ことで「間」を作り、指を止めやすくする。
- **共感or軽い反論を誘う問いかけで締める**。本文の最後やコメント欄を「これ私だけ?」
  「わかる人います?」のような共感型、または「実は逆だと思っていて」のような軽い反論を
  誘う問いかけにすると、コメントが伸びやすい。
- **箇条書き・記号のルールを統一する**。「①②③」「・」「→」などを同じ投稿内で
  揃えて使うと読みやすさが上がる。
- **実体験の生々しさ+数字をセットにする**(一行目の条件にある「具体的な数字」の強化版)。
  「〜だと思う」ではなく「実際に○件試した」「○日間続けた」のように書く。
- **独り言のような口調を混ぜる**。読者への語りかけだけでなく、「〜なんだよな」
  「〜だった」のような独り言口調を混ぜると自然さが出る。
- **本文は「結論→理由→詳細」の順で組み立てる**。先に結論、次に理由、最後に詳細という
  順番を基本にし、詳細部分は従来どおりコメント欄に送ってもよい。

### 参考:投稿の運用面のコツ(このスキルの対象外・手動で行う想定)

以下はアプリ上の操作に関するテクニックのため、このスキルでは触れるが実行はしない
(投稿文の作成までがこのスキルの範囲)。

- 「保存」より「リポスト(再投稿)」されやすい内容を意識する(保存は個人利用で終わるが、
  リポストは拡散に繋がる)。
- 他の投稿への「引用返信」を使うと露出が増えやすいと言われる。
- 投稿タイミングは「日曜の夜」「平日の朝」が比較的伸びやすいと言われる。
- 自分の投稿に自分で返信して、フォロワーのタイムラインに再度浮上させる(リマインド)
  手法もある。

## 使い方(ワークフロー)

1. ユーザーからテーマ・伝えたい内容・ターゲット層をヒアリングする(不明なら質問する)。
   アフィリエイトが絡む場合は、紹介したい商品・サービスとASP(楽天アフィリエイト、
   A8.netなど)も確認する。
2. 上記の条件に沿って**一行目の候補を複数**作る。強い言葉/会話形式/意外性のいずれかの
   切り口を使い分ける。
3. 本文(3〜8行)を書く。続き・結論・具体的なやり方などの「答え」部分は本文に書かず、
   コメント欄用の文章として別出しする。アフィリエイト絡みの投稿は「3. アフィリエイトを
   組み込む場合」のルールも適用する。
4. 完成した「本文」と「コメント欄用の文章」をセットでユーザーに提示する。複数本セットの
   依頼では、価値提供投稿とアフィリエイト絡み投稿の比率(目安9:1)も明示する。
5. ユーザーからのフィードバックを受けて微調整する。実際の投稿(公開)は行わず、
   投稿文の作成・提案までを行う。

## 注意

- このスキルは投稿**文面の作成**を行うものであり、Threadsへの自動投稿(API連携など)は
  行わない。実際にThreadsアプリ/Webへ投稿する作業はユーザー自身が行う想定。
- 元にした動画スクリーンショットは一部が画面端で切れており、読み取れなかった細則が
  存在する可能性がある。ルールの意図が曖昧な依頼が来た場合は、無理に断定せず
  ユーザーに確認する。
