# SNSマーケティングチーム 週次サイクル

目標: **アフィリエイト収益 月30万円**(詳細は `sns-team/目標とKPI.md`)

## チーム構成
| 担当 | サブエージェント | 役割 |
|---|---|---|
| SNS分析 | `sns-analyst` | 実績データの分析、ボトルネック特定、次の打ち手の提案 |
| アフィリエイト | `affiliate-manager` | 案件の選定・管理、収益試算、今週推す案件の決定 |
| 投稿の下書き | `sns-writer` | 分析と案件をもとに投稿文を作成 |
| 投稿のチェック | `post-checker` | 法令・規約・品質・炎上リスクを審査し承認/要修正を判定 |

## 進め方
引数で特定の担当だけ指定された場合は、その担当だけを動かす。指定がなければ以下を順番に実行する。

1. **前提確認**: `sns-team/目標とKPI.md` の「決めておくこと」が未記入なら、ユーザーに確認してから進める
2. **分析**: `sns-analyst` に `sns-team/data/posts.csv` の分析を依頼する(データが空なら、初期戦略と計測方法の提案を依頼)
3. **案件選定**: `affiliate-manager` に、分析結果を踏まえて今週推す案件(最大3つ)と訴求ポイントを決めてもらう
   - 2と3は独立しているので、データが空の初回は並列で実行してよい
4. **下書き**: `sns-writer` に、分析レポートと案件情報を渡して1週間分の投稿下書きを作ってもらう
5. **チェック**: `post-checker` に全下書きを審査してもらう
6. **差し戻し**: `要修正` があれば `sns-writer` に修正させ、再度 `post-checker` に通す(最大2往復。それでも解決しなければ人間に判断を仰ぐ)
7. **まとめ**: ユーザーに以下を簡潔に報告する
   - 今週の結論と目標達成見込み
   - 承認済み投稿の数と一覧(ファイルパス)
   - 人間の判断が必要な事項(グレー表現、未確認の数値など)

## 守ること
- 投稿の公開・送信は行わない。公開は人間が承認済み下書きを見て行う
- 推測の数値を事実として扱わない
