# Threads バズる型 投稿量産スキル

## 使い方

1. 下の「入力する情報」のうち、空欄(〇〇)をユーザーに質問する。
   - ジャンル
   - ターゲット
   - バズる型テンプレ①②③
2. 空欄が埋まったら、下の【依頼内容】以降をそのまま実行する。
3. 空欄のまま作らない。分からない項目は「分からない」と伝えて聞き直す。
4. 資料に無い数字・実績・固有名詞は書かない。

## 実行するプロンプト(原文のまま)

【依頼内容】
あなたはThreadsアフィリエイト×SNS分析のプロです。
これから「ジャンル:〇〇」で伸ばすため、
既にリサーチ済みの"バズる型テンプレ3種"を使って投稿を量産したいです。
※各テンプレの構造を忠実に守った上で文章を生成してください。

以下の条件に沿って、
・バズる型①
・バズる型②
・バズる型③
の3パターンそれぞれで、投稿文サンプルを複数生成してください。

【入力する情報】
ジャンル:〇〇
ターゲット:〇〇
バズる型テンプレ①:〇〇
バズる型テンプレ②:〇〇
バズる型テンプレ③:〇〇

【出力フォーマット】
▼バズる型①の投稿例(1投稿)
▼バズる型②の投稿例(1投稿)
▼バズる型③の投稿例(1投稿)

【条件】
・Threads特有のテンポ感、読みやすさ、共感→価値提供→余白の流れ
・ターゲットの"本音"を1つ必ず含める
・悩み→気付き→行動の順で刺さる構成
・アフィリエイトをする前提
・同じ型でも切り口を変えて量産性を確保
・1投稿100〜250文字
・バズる言い回しと口癖(正直言うと/知らないと損 etc)も適度に使用
・構成はテンプレそのままで作る

【出力】
上記に沿って、3つの型それぞれから計15投稿を作成してください。

## 注意

- 投稿の公開(Threadsへの実際の投稿)は、このスキルの対象外。文面をコピーして自分で貼り付ける。
