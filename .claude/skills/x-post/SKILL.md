# X(旧Twitter)投稿文作成スキル

X(旧Twitter)で伸びる投稿文を、Xの評価軸に合わせた型で作成する。
`.claude/skills/threads-post/SKILL.md`(Threads版)の考え方をベースに、Xの仕様・
アルゴリズム傾向に合わせて調整したもの。

## Threadsとの違い(前提)

- Threadsは「投稿をタップして中まで見てもらえるか」が伸びる鍵だったが、Xは
  **インプレッション数・滞在時間・リプライ数・保存数・引用リポスト数**が評価軸の中心。
  タイムライン上で「スクロールする指を止めさせる」ことが一行目の役割になる。
- 文字数制限がある。無料アカウントは全角280文字相当(日本語だと実質140字前後)。
  X Premium等の長文投稿機能を使わない前提では、**1投稿は短く言い切る**。
  長い内容は無理に1投稿に詰め込まず、**スレッド(連続ポスト)**か
  **自分への引用/リプライで続きを書く**構成にする。
- Threadsの「コメント欄に答えを置く」に近い型として、Xでは
  **①スレッド化(1/□ 形式で連続投稿)** と **②自分の投稿への最初のリプライに
  続き・詳細を書く(セルフリプライ)** の2パターンがある。ユーザーの依頼内容の
  分量に応じてどちらかを選ぶ。

## 1. 一行目(最初のツイート)の条件

Threads版と基本方針は同じだが、文字数がより厳しいことを踏まえて簡潔にする。

- 0.2秒で意味が分かる文にする。「何の話?」と一瞬でも考えさせたら流し見される。
- 強い言葉、または会話(セリフ)、または常識を裏切る意外性のいずれかを入れる。
  - 強い言葉の例:「個人情報が全部漏れてます」
  - 会話の例:「面接10秒で『あ、君採用ね』って言われた」
  - 意外性の例:「アマニ油はマジでヤバい食べ物です」
- 具体的な名詞・数字をどれか1つは入れる(商品名・金額・年数など)。
- 「これ私のことだ」と一瞬で分かるターゲット名指しを入れる。対象は広げすぎない
  (「全員」ではなく実在する層まで具体化する)。
- 当たり前のことを書かない/指示語(それ・これ・あれ・そこ)を使わない
  (Threads版の「一行目でやってはいけないこと」と同じ)。

### Xならではの注意点

- 1投稿目は**単体で意味が通る**ようにする。「続きはスレッドで」と書くだけで
  終わらせず、1投稿目だけでも読む価値が伝わる内容にする。
- ハッシュタグは基本的に使わない(乱用は伸びを阻害しやすい)。狙いがある場合のみ
  最小限(0〜1個)に留める。
- 絵文字は多用しない。強調したい語は「」で囲むか、改行で目立たせる。

## 2. 本文・スレッドの組み方

- **1投稿の目安は全角70〜120字程度**(280字上限に対して、改行を入れつつ
  読みやすい分量)。上限ギリギリまで詰め込まない。
- 内容が短くまとまる場合 → 1投稿で完結させ、深掘りしたい情報だけ
  **自分への最初のリプライ**に続きを書く(セルフリプライ形式)。
- 内容にステップ・複数の論点がある場合 → **スレッド化**する。
  - 1投稿目 = フック(結論やインパクトのある一文のみ)
  - 2投稿目以降 = 「1/」「2/」等の通し番号、またはリプライで連番にせず
    自然に読める文章で1論点ずつ区切る
  - 最後の投稿 = まとめ、または行動を促す一文で締める
- 一文をとにかく短くする。「そもそも」「やっぱり」「〜くらい」など無くても
  意味が通る言葉は削る。
- 目立たせたい単語は「」で囲む。
- 漢字にできる言葉をひらがなのままにしない(誤読防止)。
  例:「置いてある」を「おいてある」と書くと「おいおい」と読めてしまう。

## 使い方(ワークフロー)

1. ユーザーからテーマ・伝えたい内容・ターゲット層をヒアリングする(不明なら質問する)。
2. 内容量を見て「単発+セルフリプライ」か「スレッド」かを決める(迷う場合は
   ユーザーに確認する)。
3. 一行目(1投稿目)の候補を複数作る。強い言葉/会話形式/意外性のいずれかの
   切り口を使い分け、文字数(全角70〜120字目安)を意識する。
4. 本文を組み立てる。単発なら続き・詳細をセルフリプライ用として分けて書く。
   スレッドなら各投稿を文字数内に収めて分割する。
5. 完成した投稿(1件ずつ、または連番)をユーザーに提示する。文字数の目安を
   超えていないか確認する。
6. ユーザーからのフィードバックを受けて微調整する。実際の投稿(公開)は行わず、
   投稿文の作成・提案までを行う。

## 注意

- このスキルは投稿**文面の作成**を行うものであり、Xへの自動投稿(API連携など)は
  行わない。実際にXアプリ/Webへ投稿する作業はユーザー自身が行う想定。
- 文字数の目安は一般的な傾向に基づく参考値であり、アカウントの契約プラン
  (X Premium等)や実際のアルゴリズム挙動によって最適値は変わりうる。
  厳密な文字数制限が必要な場合はユーザーに確認する。
