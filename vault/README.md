# Obsidian Vault

このフォルダは Obsidian の保管庫（vault）です。Obsidianアプリで
このフォルダ（`vault/`）を「保管庫を開く」から開いてください。

## フォルダ構成

```
vault/
├── .obsidian/          Obsidian本体の設定（プラグイン有効化設定を含む）
├── daily/              デイリーノート（Calendarプラグインで利用）
├── templates/           テンプレート（Templaterプラグインで利用）
└── notes/               通常のノート
```

## 設定済みのコミュニティプラグイン

以下のプラグインを `.obsidian/community-plugins.json` で有効化し、
関連設定（`data.json` 等）を用意しています。

- **Dataview** — ノートをクエリで一覧・集計表示
- **Templater** — テンプレートから動的にノートを生成（デイリーノートに自動適用）
- **Calendar** — カレンダーからデイリーノートへ移動

## プラグイン本体のインストールについて（重要）

このリポジトリには各プラグインの `manifest.json` と設定ファイルのみを
配置しています。プラグイン本体のコード（`main.js` 等）は、
本セッションのネットワークポリシーにより GitHub からの取得が
ブロックされているため同梱できませんでした。

vault を開いた後、Obsidian上で以下の操作を行ってください。

1. 設定 → コミュニティプラグイン → 「制限モードを無効にする」
2. 「閲覧」から `Dataview` / `Templater` / `Calendar` をそれぞれ検索してインストール
   （インストール後は既存の `.obsidian/plugins/<id>/` 内の
   `manifest.json` や `data.json` が設定として引き続き使われます）
3. 各プラグインを有効化

インストール後は設定内容（テンプレートフォルダやデイリーノートの保存先など）は
既に反映された状態になっています。
