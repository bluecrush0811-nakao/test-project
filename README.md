# test-project

このリポジトリは、動作確認や開発手法の検証を目的としたテスト用プロジェクトです。

## このプロジェクトについて

新しいツールやワークフロー、コードの挙動を試すためのサンドボックスとして使用します。
本番運用を前提としたものではなく、実験・検証・学習目的での利用を想定しています。

## My Secretary (自分専用の秘書アプリ)

タスク・スケジュール(リマインダー)・メモをまとめて管理できる、
シンプルなパーソナルアシスタントのWebアプリです。外部サービスやサーバーは
不要で、ブラウザの `localStorage` にデータを保存します。

### 使い方

`index.html` をブラウザで開くだけで利用できます。

```
open index.html   # macOS
# もしくは任意のブラウザで index.html を開く
```

主な機能:

- **今日のタスク**: やることを追加・完了チェック・削除
- **スケジュール・リマインダー**: 時刻付きの予定を追加(自動で時刻順に表示)
- **メモ**: 自由記述のメモを追加・削除
- **データの引き継ぎ**: 全データをJSONファイルにエクスポート/インポート

すべてのデータはブラウザ内(`localStorage`)に保存されるため、同じブラウザで
再度開いた際も内容が保持されます。

### 機種変更・別の端末へのデータ引き継ぎ

`localStorage` のデータは端末・ブラウザごとに保存され、ブラウザの同期機能でも
移行されません。別の端末へ移す場合は、画面下部の「データの引き継ぎ」から操作します。

1. 旧端末で「エクスポート」を押し、`my-secretary-backup-YYYY-MM-DD.json` を保存する
2. そのファイルを新端末へ移す(クラウドストレージ、メール、AirDrop など)
3. 新端末で「インポート」を押してファイルを選ぶ(現在のデータは置き換えられます)
