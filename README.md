# test-project

このリポジトリは、動作確認や開発手法の検証を目的としたテスト用プロジェクトです。

## このプロジェクトについて

新しいツールやワークフロー、コードの挙動を試すためのサンドボックスとして使用します。
本番運用を前提としたものではなく、実験・検証・学習目的での利用を想定しています。

## My Secretary (自分専用の秘書アプリ)

タスク・スケジュール(リマインダー)・メモをまとめて管理できる、
シンプルなパーソナルアシスタントのWebアプリです。外部サービスやサーバーは
不要で、ブラウザの `localStorage` にデータを保存します。

### 使い方

`index.html` をブラウザで開くだけで利用できます。

```
open index.html   # macOS
# もしくは任意のブラウザで index.html を開く
```

主な機能:

- **今日のタスク**: やることを追加・完了チェック・削除
- **スケジュール・リマインダー**: 時刻付きの予定を追加(自動で時刻順に表示)
- **メモ**: 自由記述のメモを追加・削除

すべてのデータはブラウザ内(`localStorage`)に保存されるため、同じブラウザで
再度開いた際も内容が保持されます。

## ROOM投稿アシスタント (ふるさと納税 × 旅行)

楽天ROOMへの投稿を「半自動化」するツールです。ふるさと納税の旅行関連返礼品
(トラベルグッズ・旅行クーポン・宿泊券)を探し、紹介文を自動で作り、
ROOMの投稿画面をワンクリックで開きます。最後の「投稿」ボタンだけ自分で押します。

> 楽天ROOMには公式の投稿APIがなく、画面の自動操作による投稿は規約違反や
> アカウント停止のおそれがあるため、完全自動投稿にはしていません。

### 使い方

1. [楽天ウェブサービス](https://webservice.rakuten.co.jp/) でアプリIDを取得する(無料)
2. `rakuten-room/index.html` をブラウザで開き、「設定」にアプリIDを入力する
   (アフィリエイトIDは任意)
3. 「スーツケース」「旅行クーポン」などのボタン、またはキーワードで返礼品を検索する
4. 自動で作られた紹介文を必要に応じて編集し、「コピーしてROOMで開く」を押す
5. ROOMの画面で紹介文を貼り付けて投稿し、ツールに戻って「投稿済みにする」を押す

主な機能:

- **返礼品検索**: 楽天市場 商品検索APIで「ふるさと納税 + キーワード」を検索。
  自治体ショップ(ショップコードが `f` + 自治体コード)の商品だけに絞り込み可能
- **紹介文の自動作成**: トラベルグッズ用・旅行券/宿泊用の2種類のテンプレートで、
  自治体名・寄付額・レビュー・ハッシュタグ入りの文章を作成
- **投稿済み管理**: 投稿した商品を記録し、検索結果から非表示にして二重投稿を防止

設定と投稿済みリストはブラウザ内(`localStorage`)に保存されます。
