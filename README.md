# test-project

このリポジトリは、動作確認や開発手法の検証を目的としたテスト用プロジェクトです。

## このプロジェクトについて

新しいツールやワークフロー、コードの挙動を試すためのサンドボックスとして使用します。
本番運用を前提としたものではなく、実験・検証・学習目的での利用を想定しています。

## My Secretary (自分専用の秘書アプリ)

タスク・スケジュール(リマインダー)・メモをまとめて管理できる、
シンプルなパーソナルアシスタントのWebアプリです。外部サービスやサーバーは
不要で、ブラウザの `localStorage` にデータを保存します。

### 使い方

`index.html` をブラウザで開くだけで利用できます。

```
open index.html   # macOS
# もしくは任意のブラウザで index.html を開く
```

※ クラウド同期機能(後述)を使う場合は `file://` では動作しないため、
`python3 -m http.server 8000` などローカルサーバー経由で開いてください。

主な機能:

- **今日のタスク**: やることを追加・完了チェック・削除
- **スケジュール・リマインダー**: 時刻付きの予定を追加(自動で時刻順に表示)
- **メモ**: 自由記述のメモを追加・削除

すべてのデータはブラウザ内(`localStorage`)に保存されるため、同じブラウザで
再度開いた際も内容が保持されます。

### リマインダー通知

「スケジュール・リマインダー」欄の「通知を有効にする」ボタンからブラウザの通知
許可を出すと、登録した予定の時刻になったタイミングでブラウザ通知が届きます。
通知を許可していない場合でも、該当する予定がアプリ内でハイライト表示されます。

- 同じ予定は1日1回だけ通知されます
- 通知はページを開いている間だけ動作します(バックグラウンドの常時監視や
  タブを閉じた状態でのプッシュ通知には対応していません)
- ブラウザで通知をブロックしている場合は、ブラウザの設定から許可してください

### クラウド同期(Google ドライブ)

タスク・スケジュール・メモのデータを Google ドライブ経由で複数のブラウザ/端末間
で同期できます。サーバーは使わず、あなた自身の Google アカウントの中にある
「アプリ専用の隠しフォルダ(appDataFolder)」にJSONファイルとして保存する
仕組みです(通常のドライブ画面には表示されません)。

**事前準備(初回のみ、Google Cloud Consoleでの作業)**

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成(または既存のものを使用)
2. 「APIとサービス」→「ライブラリ」から **Google Drive API** を有効化
3. 「APIとサービス」→「OAuth同意画面」を設定(External / テストユーザーとして自分のGoogleアカウントを追加すればOK)
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
   - アプリケーションの種類: **ウェブアプリケーション**
   - 「承認済みのJavaScript生成元」に、`index.html` を配信するURLを追加
     (例: `http://localhost:8000` — ローカルで試す場合は
     `python3 -m http.server 8000` などで配信してください。
     `file://` で直接開いた場合はGoogleログインが動作しません)
5. 発行された **クライアントID** をコピー

**アプリ側の設定**

1. 「クラウド同期(Google ドライブ)」欄にクライアントIDを貼り付けて「保存」
2. 「Googleでログイン」をクリックし、アクセスを許可
3. 「⬆ アップロード」でこのブラウザのデータをGoogleドライブへ保存
4. 別のブラウザ/端末で同じ手順(同じクライアントID・同じGoogleアカウントでログイン)を行い、
   「⬇ ダウンロード」でデータを取得

**同期の仕組みに関する注意**

- 同期は手動です(アップロード/ダウンロードのボタンを押したときだけ通信します)
- ダウンロードするとローカルのデータは Google ドライブ側の内容で **上書き** されます
  (自動マージはしません。複数端末で同時に編集した場合は、後からアップロードした方が残ります)
- ログイン状態(アクセストークン)はページを開いている間だけ保持されます。
  再読み込みすると再度「Googleでログイン」が必要です
- リクエストされる権限は `drive.appdata`(アプリ専用データ)のみで、
  あなたの他のドライブファイルにはアクセスしません

## プロジェクト構成

現時点でのフォルダー構成は以下の通りです。

```
test-project/
├── README.md
├── index.html      # My Secretary アプリの画面
├── style.css       # スタイル定義
├── script.js       # アプリのロジック(localStorageで永続化)
├── drive-sync.js   # Googleドライブとのクラウド同期ロジック
├── sample.txt
├── vault/              Obsidian保管庫（vault）。詳細は vault/README.md を参照
└── .claude/
    └── skills/
        ├── threads-post/   # Threads投稿文作成スキル(SKILL.md)
        └── x-post/         # X(旧Twitter)投稿文作成スキル(SKILL.md)
```

新しいファイルやディレクトリを追加した際は、このセクションも合わせて更新してください。
